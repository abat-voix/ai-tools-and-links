# Фильтр организации и HNSW

Скрипт создаёт 12 000 синтетических трёхмерных векторов. К организации 42
относится 1% строк. Три запроса сравнивают ответ HNSW без дополнительного
обхода, HNSW с `strict_order` и точный поиск при одном и том же фильтре.

Нужна тестовая PostgreSQL с pgvector 0.8 или новее. Роль должна иметь право
создать расширение, если оно уже не установлено.

```bash
psql "$DATABASE_URL" -f filtered-ann.sql
```

Сравните `actual rows` у `Limit`, `Rows Removed by Filter` и тип плана.
Число 0,4 — ожидаемое число прошедших фильтр из 40 кандидатов при равномерной
доле 1%. Фактическая выдача зависит от данных и построенного графа. При
`strict_order` порядок найденных строк сохраняется, но поиск остаётся
приближённым. Чтобы сравнить полноту выдачи, уберите `EXPLAIN` и сопоставьте
идентификаторы с точным запросом.

В проверочном запуске на pgvector 0.8.7 получили 1, 10 и 10 строк соответственно.

Все изменения завершаются `ROLLBACK`. [Фильтрация в pgvector](https://github.com/pgvector/pgvector#filtering)
