# Офлайн-проверка решения о выпуске

Пять эталонных обращений и два сохранённых прогона показывают решение по доступу, действию и ответу. Все обращения, ответы, действия и сохранённая оценка судьи в этом каталоге — синтетические фикстуры. Скрипт читает файлы на стандартной библиотеке Python, не вызывает сервис и не обращается к модели.

```bash
python3 -m unittest -v test_gate.py
python3 run_evaluation.py --output /tmp/support-good-report.json
python3 run_evaluation.py --run runs/synthetic-access-violation.jsonl
```

Второй запуск возвращает код 0 и долю 5/5. Третий возвращает код 1 при доле 4/5, которая проходит порог 0,8. Нарушение доступа и критическая ошибка блокируют выпуск независимо от средней доли. `review` и `error` сохраняются в знаменателе и тоже блокируют выпуск. Существующий файл отчёта не перезаписывается.

Каждый эталон содержит вопрос, категорию, факты инструмента, обязательные сведения, запреты и критичность. `expected_access` и `expected_action` задают проверяемую границу. В прогоне поле `action` отражает фактическое действие с разобранными аргументами, а `access` — результат проверки доступа. При подключении сервиса эти сведения берутся из доверенной трассы приложения. Их нельзя восстанавливать из текста ответа модели. Офлайн-фикстуры демонстрируют логику проверки и не подтверждают реализацию авторизации в сервисе.

Для четырёх коротких ответов выполняется простая проверка обязательных и запрещённых фрагментов. Она демонстрирует автоматическое утверждение для узкого сценария. Свободные формулировки и смысловые обещания требуют рубрики и проверки судьи. Пятый пример принимает сохранённые `verdict`, `evidence`, `model`, `rubric_version`. Отсутствующая или неполная оценка считается ошибкой. Синтетическая оценка не подтверждает качество настоящего судьи.

Отчёт содержит версию промпта, версию набора, SHA-256 исходного JSONL, долю и результат каждой строки. Для повторного запуска указать новый путь `--output`. Фиксированный порог 0,8 выбран для демонстрации.

Для полного прогона расширьте набор минимум до двадцати обращений. Вызовите HTTP-сервис и судью через Responses API, проверьте судью на человеческой разметке и запишите задержку, расходы и метаданные прогона. Этот небольшой пример покрывает офлайн-проверку сохранённого артефакта. Он не заменяет реализацию оценщика и прогон сервиса из задания.
