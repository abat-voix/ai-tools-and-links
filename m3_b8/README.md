# m3_b8 — пример отчёта garak (безопасность)

Каталог с готовым примером отчёта [NVIDIA garak](https://github.com/NVIDIA/garak/) для домашней работы по безопасности ИИ-приложения. Это образец того, как оформить `docs/security/garak_baseline_<date>.md` по итогам своего прогона.

## Что внутри

- `garak-baseline-demo.md` — читаемый пример отчёта: конфигурация прогона, таблица «проба → доля успешных атак → вердикт», реальные примеры пробитий (что отправили → что ответила модель) и разбор, где модель устояла.
- `garak-baseline-demo.html` — та же сводка, сгенерированная самим garak: кликабельная таблица по пробам, удобно листать в браузере.

## Как этим пользоваться

Прогон в примере сделан против эталонного FastAPI-сервиса (тот же сервис, что в каталоге `m3_b5`) без защитного слоя — «голая» модель. Задача — повторить такой же прогон против своего сервиса и оформить отчёт в той же структуре: заголовок и конфигурация → таблица результатов → 3–5 примеров пробитий → выводы. После добавления защитного слоя делается второй прогон (`garak_after_<date>.md`) и строится таблица дельты «было / стало / закрыли».

Пример-прогон исторический, на модели `gpt-4o-mini`; на `gpt-5.4-mini` порядок цифр сопоставим (базовая незащищённая модель пробивается простой инъекцией в 60–70 % случаев). Полная постановка задания и шаблон отчёта — в описании домашней работы в LMS.
