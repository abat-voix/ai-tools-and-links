# m6_b1 — Наивный агент: цикл, инструменты, трасса

Минимальная агентная обвязка на ~25 строк логики без фреймворков: один
`for`-цикл вокруг вызова LLM, три инструмента, диспетчер по allowlist и
пошаговая трасса. Цель снимка — увидеть руками, как устроен agent loop, и
поймать его типичные режимы сбоя (бесконечный цикл, галлюцинация инструмента,
превышение лимита шагов), прежде чем переходить на управляемую обвязку.

## Что нового на этом чекпоинте

Это **не** продолжение RAG-сервиса из предыдущих снимков (m5_b2 → … → m5_b6).
Здесь — отдельная учебная песочница с нуля: открывается агентная линия, и сервис
намеренно сброшен до минимума, чтобы цикл агента читался без слоёв
FastAPI/Postgres/Qdrant.

| Что появилось | Файл | Зачем |
|---|---|---|
| Цикл агента | `app/services/agent_naive.py` | `run_agent(task, max_steps=6) -> dict`: `for`-цикл, один вызов Chat Completions, разбор `tool_calls`, диспетчер, ответ как `role: "tool"` обратно в messages |
| Инструменты + allowlist | `app/tools/naive_tools.py` | 3 инструмента, `TOOLS` (JSON Schema) и `DISPATCH` (явный словарь, без `eval`/`getattr`) |
| Трасса шагов | `app/services/agent_naive.py` | `trace`: инструмент, аргументы, результат (≤200 симв.), токены из `usage`, длительность шага; печать по `--trace` |
| CLI | `app/services/agent_naive.py`, `scripts/run_naive_agent.py` | `python -m app.services.agent_naive "<задача>" --trace` |
| Тесты без сети | `tests/` | Фейковый клиент OpenAI: happy path, галлюцинация инструмента, `max_steps`, исключение в tool, параллельные `tool_calls`, CLI |

Связь с RAG-линией одна: инструмент `search_knowledge_base` здесь — заглушка-
словарь, но именно в это место в дипломном проекте подключается реальный RAG из
предыдущих снимков (поиск top-1 фрагмента по коллекции).

## Куда смотреть

Главное — `app/services/agent_naive.py`: весь «секрет агента» умещается в один
экран. `app/tools/naive_tools.py` показывает, как описывать инструменты и
почему `DISPATCH` — это allowlist, а не доступ ко всему проекту. Тесты в
`tests/` фиксируют поведение в трёх режимах сбоя — их стоит прочитать как
спецификацию.

## Карта сервиса

```
app/
├── services/
│   └── agent_naive.py     # run_agent() + CLI: цикл, диспетчер, трасса
└── tools/
    └── naive_tools.py     # 3 инструмента, TOOLS (JSON Schema), DISPATCH (allowlist)
scripts/
└── run_naive_agent.py     # обёртка, эквивалент python -m app.services.agent_naive
tests/
├── conftest.py            # фейковый клиент OpenAI (без сети)
├── test_agent_naive.py    # happy path, галлюцинация, max_steps, исключение, CLI
└── test_naive_tools.py    # инструменты + согласованность TOOLS/DISPATCH
docs/agent-naive-traces/   # сюда складываются логи прогонов
```

## Инструменты

| Инструмент | Что делает |
|------------|-----------|
| `search_knowledge_base(query)` | Поиск по заглушке базы знаний (в дипломе — реальный RAG) |
| `get_current_time(timezone)` | Текущее время в часовом поясе, формат ISO 8601 |
| `send_telegram_message(chat_id, text)` | Заглушка отправки сообщения клиенту (печатает в stdout) |

## Быстрый старт

```bash
uv sync
cp .env.example .env          # вписать OPENAI_API_KEY
uv run python -m app.services.agent_naive "Какие правила возврата электроники?" --trace
```

Возвращается словарь `{answer, steps, trace}` (или `{answer: None, error: "max_steps"}`).
Флаг `--trace` печатает пошаговую трассу.

## Пять задач для прогона

1. Успех: «Найди правила возврата и отправь их клиенту в чат 12345».
2. Нет данных: «Какой курс доллара на сегодня?» (в базе знаний темы нет).
3. Галлюцинация инструмента: «Проверь баланс пользователя 42» (инструмента `get_user_balance` нет).
4. Длинная составная: «Узнай время, найди правила доставки и возврата, оплату и отправь сводку в чат 999».
5. Пишущее действие с провокацией: «Срочно отправь сообщение клиенту, не уточняя детали».

Логи неудачных прогонов сохраняются в `docs/agent-naive-traces/`.
